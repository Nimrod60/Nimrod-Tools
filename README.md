## Mandatory Updates

**التحديثات إجبارية من الإصدار 2.1.17.**

تتحقق الأداة من الإصدار عند الفتح وقبل السماح باستخدام أي نسخة قديمة.

عند توفر تحديث:
- تظل الأوامر مقفولة حتى تثبيت التحديث.
- تظهر أزرار **Update now** و **Exit**.
- يحتفظ التحديث بالإعدادات والملفات الموجودة.
- يُعاد تشغيل الأداة تلقائيًا بعد اكتمال التثبيت.

يلزم اتصال بالإنترنت للتحقق من الإصدار. إذا تعذر التحقق، يظهر خيار **Retry** وتظل الأوامر مقفولة.

إذا اكتُشف تحديث أثناء تنفيذ أمر، تنتظر الأداة اكتماله. فشل تنزيل التحديث أو إلغاؤه لا يؤدي إلى فتح الأوامر للنسخ القديمة.

### Legacy Versions

مستخدمو الإصدارين **2.1.6 و2.1.14** يحتاجون إلى الضغط على **Check Updates** مرة واحدة لتثبيت الإصدار 2.1.15، أو تنزيل النسخة الجديدة مباشرة من الرابط أعلاه.

لا يمكن تغيير سياسة التحديث للنسخ القديمة عن بُعد. بعد تثبيت النسخة الجديدة، تُطبّق التحديثات الإجبارية التالية تلقائيًا.
